# Antigravity (agy) 历史运行 TPS 性能统计分析报告

## 1. 核心指标概览

| 指标项 | 统计值 | 说明 |
| :--- | :--- | :--- |
| **采样样本总量** | **1,891 轮** | 覆盖 2026-09-19 至 2026-10-09 全量 29 个会话库 |
| **总生成 Token 规模** | **728,774 Tokens** | 包含模型思考过程 (Thinking) 与正文交付 |
| **累计纯生成耗时** | **9193.38 秒** (~2.55 小时) | 仅计入模型端流式生成净耗时 |
| **最小吞吐率 (Min TPS)** | **3.46 TPS** | 偶发长 Prompt 复杂推理首字冷启动/网络抖动 |
| **最大吞吐率 (Max TPS)** | **2065.21 TPS** | 高速轻量模型极速并行输出或缓存击穿 |
| **中位数 (Median / P50)** | **46.14 TPS** | 50% 的日常推理轮次维持在此基准以上 |
| **算术平均值 (Mean)** | **82.18 TPS** | 各轮次单次 TPS 的算术平均 |
| **加权平均值 (Weighted TPS)** | **79.27 TPS** | 全局总 Token 数 / 全局总耗时（真实系统吞吐） |
| **标准差 (Std Dev)** | **117.35** | 反映高低负载模型的跨度与离散度 |
